# code_2026y_A
Code and data for "State-dependent roles of inflammation across pain conditions: insights from human transcriptomics"

# How to start?
<ul>
  <li>Download the zipped tarball from this project</li>
</ul>

Next, unzip the tarball;
```bash
tar -xvf archive.tar.gz
```

# What's included
<ul>
  <li><b>commands_archive.txt</b> - BASH code for (most of) the project</li>
  <li>Phenotypic and transcriptomic <b>data</b> for each cohort</li>
  <li>A couple of resource files; pathways, ps2eps, etc.</li>
</ul>

# Required R packages and programs
The R packages used to compile the results are listed at the top of the commands_archive.txt file. YMMV.

# What's not included
<ul>
  <li>The R packages themselves</li>
  <li>The output files - they are huge! We have them to compare if needed</li>
  <li>The code for the LOCO analysis; it can be derived from the distributed code herein</li>
  <li>The code to generate Supplementary Materials</li>
</ul>
